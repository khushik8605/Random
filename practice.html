GitHub Commands

Here are some essential Git commands to help you manage your project:

  • git init – for creating a new repository on our local machine.
  • git remote – for connecting our local repository to GitHub.
  • git branch – for renaming our branch.
  • git add and git commit – for staging and committing our changes.
  • git status – for checking the status of our files.
  • git push – for pushing our code to GitHub.

This is a lot to digest! 😵‍💫 So make sure to save this:

git init
git remote add origin <repository_url>
git branch -M main
git add .
git commit -m 'Your commit message here!'
git status
git push -u origin main

07. Git Clone & Fork

👯 Working with a Team

GitHub enables multiple people to collaborate using shared repositories. Teams usually follow workflows involving cloning, branching, pushing, and pulling.

🔑 Cloning and Permissions

To clone an existing GitHub repository to your machine:

git clone https://github.com/username/repository.git

Permissions:

  • Read – View and clone
  • Write – Edit, push, and branch
  • Admin – Full control over settings and access
  • Maintainer – Like Admin (in orgs)
  • Collaborator – Read and write access

🍴 Forking

If you don’t have write access, you can fork the repository. This creates a copy under your GitHub account where you can make changes safely.

Use the "Fork" button at the top-right of any repository on GitHub, then:

  1. Keep the same name and description
  2. Copy only the main branch
  3. Do not add a new README

After forking, use git clone to work on it locally.

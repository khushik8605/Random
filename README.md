# Git Practice Project

This project is a simple HTML page that lists essential Git commands for beginners.  
It is meant to help you understand and practice how to:

- Create a local Git repository
- Connect it to a GitHub repository
- Stage, commit, and push your code
- Track the status of your project using Git commands

## 📄 File Included

- `index.html` — Contains a list of commonly used Git commands with explanations and a summary reference block.

## 🧠 Git Commands Covered

- `git init` – Initialize a local Git repository
- `git remote` – Connect local repo to a remote (like GitHub)
- `git branch` – Rename or create branches
- `git add` – Stage changes
- `git commit` – Commit changes with a message
- `git status` – Check file status
- `git push` – Push changes to GitHub
